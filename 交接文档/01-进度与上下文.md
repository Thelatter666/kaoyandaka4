## 关键技术决策与坑（务必遵守）

1. **framer-motion 已锁定 11.18.2，切勿升级**。12.42.2 存在回归：style 绑定的 MotionValue 的 `renderRequest` 渲染订阅从未建立，导致一切滚动驱动动效（useScroll/useTransform → DOM）静默失效（MV 值正确但 DOM 不更新，无报错）。若未来必须升级，须用 `e2e/verify-landing.mjs` 全量截图回归验证滚动动效。
2. **vite dev 运行中变更依赖后必须重启 dev 服务器**：`.vite/deps` 预打包缓存不会在运行中自动刷新（本次排查最大的坑，曾造成"降级无效"的假象）。
3. **useAuth mock 的同标签页陷阱**：同标签页写 localStorage 不触发 storage 事件，自动化测试写 `yantai_mock_auth` 后必须 `page.reload()`，或调用 `setMockLoggedIn(true)`。
4. **项目硬性视觉规范**（后续所有 UI 开发必须遵守）：
   - 动效只允许 `transform` / `opacity`（SVG `pathLength` 属绘制属性，获豁免）
   - 禁止裸色值，颜色必须引用 `client/src/styles/tokens.css` 的 CSS 令牌（`--color-*`）
   - 视觉延续极光玻璃 v2 双主题（`glass-1`/`glass-2` 等既有类，明/暗 `data-theme`）
5. **LCP 优化手法**：入场动画初始 `opacity: 0.01` 而非 0（元素首帧即可绘制，LCP 2.6s→0.9s，视觉无差别）。后续新页面入场动画沿用此手法。
6. **Lighthouse 测量方法**：对 `client/dist` 用带压缩的静态服务器（`npx sirv-cli dist --port 5178 --gzip --brotli --single`）+ `npx lighthouse <url> --preset=desktop`；默认 mobile 模拟 + 无压缩 preview 会严重失真。重建 dist 后必须重启 sirv（它缓存文件清单，否则会拿到 404 的旧 hash 资源）。
