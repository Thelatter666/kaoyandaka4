# 砚池 Inkstone Well — 番茄钟计时器重设计

> 状态：待用户审阅 · 分支 `redesign/pomodoro-clock` · 2026-08-21
> 前置产物：`CONTEXT.md`（术语表）、`docs/adr/0001`–`0004`、`docs/superpowers/spikes/2026-08-21-inkwell-spike.html`（交互原型）
> 本文全文使用 `CONTEXT.md` 的正式术语。旧称「光晕核心 / 进度环 / 刻度珠」一律不再使用。

## 1. 目标与非目标

**目标**：把番茄钟的计时器从「极光玻璃圆环」重做为**砚池 Inkstone Well** —— 以一方砚台墨池的墨面高度表达本轮剩余、以池壁外沿水痕表达今日累积，使产品名「砚台」首次成为视觉资产。

**非目标（边界声明）**：

| 不做 | 原因 |
|---|---|
| 落地页 `FeaturePomodoroSection.tsx` 的手工复刻环 | 用户已定：本轮不管，之后另立需求（届时应评估改为直接复用组件，消除这份复刻代码） |
| 任何业务逻辑 | `plannedEndAt` 单一真源、响铃 worker、会话恢复、统计口径一律不动 |
| 番茄钟页点火 `stage-ignite` 与舞台其余动效 | 仅动完成态切换时序（见 §7.2） |
| 提示音开关失效缺陷 | 已记录，另案处理 |
| 24 颗刻度珠的等价替代 | 水痕取代之，无上限（§4.3） |

**范围**：`RingCountdown` 组件的 `full`（番茄钟页 400px）与 `mini`（首页 120px）两个变体同步改造。

## 2. 信息编码模型

砚池同时承载两个**正交**信息，各走独立通道（ADR-0001）：

| 信息 | 通道 | 方向 |
|---|---|---|
| 本轮剩余 | 墨面高度 | 递减 |
| 今日累积 | 水痕道数 | 递增 |

墨面与中心倒计时数字**同向递减**，编码一致性优先于「积累」的情绪价值；积累感由水痕承担。

### 3.3 墨面高度映射（ADR-0003）

输入为**剩余面积占比** `f`，输出墨面高度占比 `h`：

- `f = (θ - sinθ)/2π`，`h = (1 - cos(θ/2))/2`，`f → h` 无闭式解
- **实现定为：模块加载时预生成 101 点查找表 + 每帧线性插值**。禁止每帧牛顿迭代
- 边界钉死 `h(0)=0`、`h(1)=1`；`h(0.5)=0.5` 严格成立
- 墨面 y 坐标：`surfaceY = 180 + 160 - h × 320`

实测放大倍数（末段分辨率即靠此解决）：

| f | 1% | 5% | 10% | 50% | 100% |
|---|---|---|---|---|---|
| h | 3.3% | 9.7% | 15.6% | 50% | 100% |
| 放大 | 3.3× | 1.95× | 1.56× | 1.00× | 1.00× |

## 4. 状态规格

### 4.1 状态与呈现

| 状态 | 墨面 | 文字 | 其他 |
|---|---|---|---|
| 空池（未开始） | `h = 0`，露出砚石池底与砚石纹 | 阳文，显示目标时长 + 「准备开始」 | — |
| 进行中 | `h = areaToHeight(剩余/计划)` | 阳文/阴文随墨面自动切换 | 波纹运行 |
| 低时（剩余 ≤ 300s） | 同上 | 阳文色转 `--color-timer-low` | 池壁泛金 + 波幅 ×1.6 + 周期压至 5s / 3.2s |
| 休息 | 同上，墨换 `--color-ink-break` | 模式文字「短休息 / 长休息」 | 波周期不随任务时长变；**波幅 ×1.25、反光带换 `--color-ink-highlight-break`（更亮）** |
| 完成 | 澄清序列（§5.3） | — | 结束后交由页面切完成态 |

低时阈值**沿用既有 300s 不变**（用户已有预期）。既有「数字 2s 脉动」**移除** —— 已有池壁泛金与波纹加速两个通道，第三重冗余且与阴文叠加产生视觉混乱。

### 4.2 波纹参数（Q14 定量，不留给实施猜）

| 层 | 波幅 | 空间周期 | 时间周期 | 低时 |
|---|---|---|---|---|
| 主波 | ±5.8 单位（≈±6.4px @400px） | 260 单位 | 11s | 5s，波幅 ×1.6 |
| 副波 | ±3.6 单位（≈±4.0px） | 180 单位 | 7s | 3.2s，波幅 ×1.6 |

两层即止，**不做第三层**（400px 上已不可辨）。时间周期互质，避免周期性拍频。波幅下限依据：<4px 不可察觉；上限依据：>10px 会让墨面高度估读失真。

**波幅切换的实现方式（此处定死，不留给实施）**：波幅写在 path 的 `d` 里，无法用 CSS 缩放实现（对波形组 `scaleY` 会连带拉伸整个墨体）。因此**在模块加载时预生成三套波形路径字符串**：

| 变体 | 波幅系数 | 触发 |
|---|---|---|
| 常态 | ×1 | 专注，剩余 > 300s |
| 低时 | ×1.6 | 专注，剩余 ≤ 300s |
| 休息 | ×1.25 | 短休 / 长休 |

每套含 3 条路径（主波墨体、副波墨体、主波阳文裁剪边缘 —— **阳文裁剪边缘必须与主波同幅，否则阴阳互补失效**），共 **9 条静态字符串**。状态跨越时切换 `d` 属性，每帧成本为零。

低时与休息**互斥**，无需组合变体：低时判定沿用既有 `mode === 'focus' && remaining <= 300`，休息态永不进入低时。

### 4.3 水痕

- 位置：池壁外沿，与墨面分层不冲突
- 布点：**固定 6° 间隔，自 12 点顺时针累积**；新增一道只在末尾追加，已有水痕永不移动
- 着色：**统一中性色 `--color-ink-mark`，不按科目区分**，`opacity .62`
  - 决策依据：按科目着色需要「今日每轮的科目有序序列」，而现有 `today-summary` 仅提供 `completedSessions`（轮数）与 `bySubject`（每科目**秒数**）。轮数与秒数不成正比（45 分钟一轮与 5 分钟一轮各算一轮），按秒数推算颜色会产出**错误信息**。要拿到真实序列需改动 server 统计路由 + shared schema + client 类型 + 本地模式等价实现，实质是第二个需求，突破本 spec 声明的范围。
  - 分科目分布信息由统计页承担；水痕的核心价值是「今日累积在长」。
- 溢出：满 60 道后外扩第二圈（`r` 各 +12）
- 休息**不计**水痕（休息不产生学习记录，语义一致）
- 副产品：水痕扫过的角度总和即今日专注总量的可读读数

## 5. 动效规格

### 5.1 注墨 Inking · 520ms

底部整体上升至目标高度，`cubic-bezier(0.22,1,0.36,1)`。与页面既有 `stage-ignite`（240ms）**并行但不同步收尾** —— 点火结束时墨仅涌到一半，形成「按下 → 墨随之涌上」的因果感。注满后**立即开始下降，不设停顿**（停顿会被读作卡死）。

排除方案：中心涌起（与涟漪同形，两个关键动效不应同貌）、上方倾倒（需池外壶具，mini 无法承载）。

### 5.2 波纹

纯 CSS `transform: translateX` 无限动画，与逐帧驱动**完全解耦**（§6.2）。

### 5.3 澄清 Clarify · 700ms（重叠编排）

| 区间 | 动作 |
|---|---|
| 0–280ms | 墨面去饱和转清 |
| 120–520ms | 涟漪自中心扩散撞池壁（`r: 6 → 158`，描边 7 → 1，opacity .85 → 0） |
| 420–700ms | 新水痕自内向外刻入（`scale .6 → 1` + 淡入，`--ease-spring`） |
| 700ms | 页面切完成态 → 既有 `BurstParticles` 接棒 1.2s |

水痕置于最后：它是**结果**，应在过程之后落定。澄清与粒子爆散是**串联两拍**而非叠加 —— `BurstParticles` 挂在完成卡上、此时砚池已隐藏。

**澄清期间的墨面行为（歧义消解）**：澄清起始瞬间**冻结墨面高度**，不再随时间下降，在该高度上完成去饱和转清。由此两种结束方式呈现自然不同：

| 结束方式 | 冻结高度 | 观感 |
|---|---|---|
| 自然结束（计时归零） | ≈ 0，墨已见底 | 澄清以**涟漪为主**，转清几乎无对象 |
| 提前完成（手动按钮） | 尚有高度 | 转清明显，读作「还剩这么多但我收工了」 |

**明确排除**「澄清时墨面回涨至满」—— 会被读作重新开始。
**取消（cancel）不播澄清**，直接切 idle（与既有「取消不触发粒子」一致）。

### 5.4 降级（`prefers-reduced-motion: reduce`）

关闭波纹、涟漪、水痕刻入、注墨；墨面高度**直接就位**。降级后仍保有材质、颜色、墨面高度三重信息 —— **功能完整，只是不炫**。

`mini` 变体的降级形态与本降级形态**几乎同构**（静态墨面 + 阳文 + 凹陷 + 低时变色），一套实现覆盖两个场景。

## 6. 技术规格

### 6.1 SVG 结构约束（spike 已踩过的三个坑，实施必须遵守）

1. **`<clipPath>` 的子元素只能是 shape / text / use。** 不得在其中套 `<g>` 承载平移 —— 会使裁剪区为空、阳文被整体裁掉，且 `getBBox()` 不受裁剪影响，读数正常，极易误判为「渲染正常」。竖向平移放在 `<clipPath>` 自身的 `transform` 上。
2. **`mask` 必须挂在未被平移的外层组。** 挂在 `translate(0, surfaceY)` 之内会使 mask 内容坐标整体下移，挖空落到池外，阴文静默失效。
3. **砚石纹不得进入文字安全区。** 深斑点压在阳文数字下会把字糊成一团（spike 首轮即因此完全不可读）。

### 6.2 逐帧驱动

- **每帧只写一个值**：`surfaceY` → 2 个 `.surf-g` 的 `transform` + 1 个 `.surf-clip` 的 `transform`
- 波纹横向位移由 CSS 动画独立承担，**不进 rAF**
- 因此**零重渲染优化完整保留**（与现状写 `stroke-dashoffset` 同级成本）
- 排除 canvas：会丢失 mask / 裁剪的声明式能力，且颜色令牌需 JS 解析、双主题切换要手动重绘

### 6.3 组件接口变更

`RingCountdown` 对外签名保持兼容，仅两处调整：

| 项 | 变更 |
|---|---|
| `completedRoundsToday` | 语义由「点亮刻度珠数」改为「水痕道数」，上限 24 → 60（超出外扩第二圈）。**调用方无需改动** |
| `subtitle` | 因文字移入 SVG，CSS `text-overflow: ellipsis` 失效 → 改为按字宽截断：**全宽字符计 1、半宽字符计 0.5，上限 18**，超出截断并补 `…`（依据：副标题位于 `y = 中心 + 76`，该处池内弦半宽为 `√(160² − 76²) ≈ 140.8`，可用宽约 281 单位，13 号全宽字约 13 单位/字 ⇒ 容量约 21 字，取 18 留余量）|
| `progressCircleRef` | 移除（进度环不再存在），替换为 `surfaceRef` 供 `SmoothRing` 直写平移 |
| `PROGRESS_CIRCUMFERENCE` 导出 | 移除，替换为导出 `areaToHeight` 与 `SURFACE_TRAVEL`（= 320） |

`SmoothRing`（`PomodoroPage.tsx` 内）随之把每帧写 `stroke-dashoffset` 改为写 `transform`，rAF 结构不变。

## 9. 验收标准

1. **等面积映射**：`areaToHeight` 为 101 点 LUT + 线性插值；`h(0)=0`、`h(0.5)=0.5`、`h(1)=1`；序列单调不减
2. **对比度**：浅色与深色主题下，数字段 ≥3:1、副标题段 ≥4.5:1（以像素采样复测，非目测）
3. **阴阳文连续性**：墨面自 100% 拖到 0%，文字从阳转阴无跳变、无任一高度糊字
4. **末段不过载**：剩余 ≤5% 且低时警示开启时，薄墨面 + 池壁泛金 + 数字三者层次清晰、不互相干扰
5. **mini 干净**：120px 下仅墨面 + 阳文数字，无波纹 / 水痕 / 砚石纹，数字可读
