# 设计文档：网课导入修复 + 卡片限高滚轮翻阅

日期：2026-08-07
分支：`feat/course-import-zones`

## 背景与问题

网课页有 7 个分区（数学 / 英语 / 408·未分类 / 408·数据结构 / 408·计组 / 408·操作系统 / 408·网络），每个分区应能导入任意多门课程。当前三个问题叠加把导入能力堵死：

1. 右上角「导入网课」按钮硬编码打开数学分区（`CoursesPage.tsx:83` 的 `setImportZone(COURSE_ZONES[0])`），无法选择目标分区。
2. 分区卡仅在空状态（`courses.length === 0`）显示「导入」按钮；非空分区卡无再次导入入口（`CourseZoneCard.tsx:46`）。
3. 叠加后果：英语和 408 各分区导入第一门课后无法再添加第二门 → 每个分区被卡死在只能有 1 门课程。

## 期望行为

1. 右上角「导入网课」打开导入流程时可自由选择目标分区（7 分区），而非默认数学。
2. 每个分区卡无论是否已有课程，都保留「再导入一门课」入口，课程可逐门累积。
3. 卡片最多直接显示 3 门课程，鼠标悬停于卡片上时滚动滚轮可翻阅浏览全部课程。
4. 每门课程保留「>」入口点击查看详情（现状已满足：整行可点 + 行尾 ChevronRight 图标，导航至 `#/courses/{id}`，详情页维持现状）。

## 方案设计

### 改动范围

**`CoursesPage.tsx`（父级状态收敛）**
- 保持 `importZone` state 不变：右上角按钮仍默认 `COURSE_ZONES[0]`（数学）；卡片入口传入各自分区。
- 给 `ImportCourseModal` 新增两个 prop：`zones={COURSE_ZONES}`（下拉选项）、`onZoneChange={setImportZone}`（弹窗内切换分区同步父级）。

**`ImportCourseModal.tsx`（分区选择）**
- 第一步顶部（文件上传前）新增「目标分区」下拉选择器：7 个分区（数学/英语/408·未分类/408·数据结构/408·计组/408·操作系统/408·网络），选中项用 SubjectBadge 展示。
- 弹窗标题「导入{分区}课程」随选择实时更新。
- **分区切换时重置向导**：清空已粘贴文本/已上传文件/解析结果，回到第一步——解析结果绑定分区，防止「数学解析的结果导入到英语」的错位。
- 确认步「导入分区」行自动跟随（现有逻辑已用 `zone` prop，无需改）。

**`CourseZoneCard.tsx`（持续导入 + 限高滚轮）**
- 非空分区卡课程列表底部新增「再导入一门课」按钮（glass 变体 + Plus 图标，与空态按钮同风格）。
- 课程列表容器改滚动：`max-height: 3 行（132px）`，`overflow-y: auto`。
  - 课程 ≤3 门：自然高度，无滚动条。
  - 课程 >3 门：滚轮悬停于卡片上即可翻阅全部课程；滚动条默认隐藏、hover 卡片时淡入细滚动条（`::-webkit-scrollbar` 8px 圆角，不占位）。
- 列表行交互不变（整行可点进详情 + 行尾 `>` + 行尾删除图标）。

**CSS**
- `ImportCourseModal.css`：下拉选择器样式（复用 `fieldStyle` 变量体系）。
- `CourseZoneCard.css`：课程列表滚动容器样式 + 底部「再导入一门课」按钮布局样式。

### 数据流

```
卡片「再导入一门课」→ onImport(该分区) → 弹窗下拉默认该分区
右上角「导入网课」→ 默认数学 → 弹窗内下拉可切任意分区
弹窗内切换 → onZoneChange → 父级 importZone 同步 + 弹窗内向导重置
滚轮翻阅：纯 CSS 滚动容器，无 JS 事件处理
```

### 边界（不做的事）

- 不改后端 API（`subject`/`subSubject` 参数已支持任意分区）。
- 不改解析/导入三步流程。
- 不做「记住上次选择的分区」持久化。
- 详情页维持现状（hero 信息卡 + 集数列表 + 完成切换 + 开始学习 + 删除）。
- 触屏/键盘无障碍：滚动容器原生支持触控滚动；键盘用户 Tab 可达列表内课程按钮。

## 术语表

| 术语 | 含义 |
|------|------|
| 分区（Zone） | 网课 7 个分类卡片，由 subject + subSubject 唯一定位 |
| 课程（Course） | 某分区下的一门网课，含集数与时长进度 |
| 导入弹窗 | 三步向导（粘贴 → 预览 → 确认）的 Modal |
| 再导入一门课 | 非空分区卡底部的持续导入入口按钮 |
