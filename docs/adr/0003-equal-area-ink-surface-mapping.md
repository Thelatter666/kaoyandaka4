# 墨面高度按等面积映射，而非线性高度映射

砚池以墨面高度表达剩余比例。显而易见的做法是让高度与剩余比例线性对应（`h = f`），但圆形容器底部收窄，末段的高度变化会被压缩到几乎看不出来 —— 而末段（剩余不足 5 分钟）恰恰是最需要被感知的时刻。因此墨面高度改由**剩余面积**决定：把「剩余面积占比」当作输入，求出对应的弓形高度。

弓形面积与高度的关系为 `f = (θ - sinθ)/2π`、`h = (1 - cos(θ/2))/2`，`f → h` 无闭式解。实现方式定为**模块加载时预生成 101 点查找表 + 每帧线性插值**；排除每帧牛顿迭代（引入收敛性风险，换取毫无意义的精度）。

## Consequences

- 末段高度分辨率被放大（实测：剩余 10% → 高度 15.6%，约 1.56×；5% → 9.7%，约 1.95×；1% → 3.3%，约 3.3×）。
- 副作用是墨面下降**非匀速**（中段慢、两端快）。在液体语境下这符合「窄处流速快」的物理直觉，属可接受代价。
- `f = 0.5` 时 `h = 0.5` 严格成立，映射在中点对称。
- **这不是可以「顺手简化」的代码**：把 `areaToHeight(f)` 换回 `f` 会静默摧毁末段可读性，且不会有任何测试报错。
