# 墨面随时间下降，而非上涨

砚池以墨面高度表达一轮专注的进度。产品整体价值观是「积累」（学习森林、种树、今日轮次都在做加法），因此让墨面**上涨**在情绪上更贴合；但砚池中心的倒计时数字显示的是**剩余时间**，若墨面上涨而数字递减，两个编码方向相反，会造成认知冲突。我们选择编码一致性优先：**墨面与数字同向递减**。

积累感不由墨面承担，改由**水痕**表达（今日每完成一轮追加一道，只增不减）。因此砚池同时承载两个正交信息：墨面递减 = 本轮剩余，水痕递增 = 今日累积。

## Consequences

- 「墨越用越少」的负面联想由水痕的持续增长抵消，两者必须成对存在；若未来移除水痕，本决策需重新评估。
- 沙漏与水钟的文化直觉（时间往下漏）与本方案一致，属额外收益。
