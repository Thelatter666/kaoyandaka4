# 计时文字移入 SVG，以两层互补裁剪实现阴阳文

墨面会纵向穿过砚池中心的计时文字。若文字沿用 HTML 覆盖层，墨面经过时深墨底与深色文字对比度崩塌，且这不是边缘情况——每一轮都会发生。我们把文字移入 SVG，并以**两层互补裁剪**呈现：墨面之上的部分为**阳文**（实体填色），墨面之下的部分为**阴文**（以文字为 mask 从墨中镂空，透出池底）。两层共用同一个墨面高度做互补裁剪，墨面推进时文字自动从阳转阴，连续无跳变。

选择 SVG `<mask>` 而非 `mix-blend-mode`：前者跨浏览器行为确定，后者在不同混合底色下结果不可控。

## Considered Options

- **描边/外发光硬扛**：糊弄，两种主题下都难同时达标。
- **文字移出池外**：破坏中心焦点，砚池不再是单一视觉主体。
- **限制墨面不进入文字带**：直接砍掉可用的编码范围，末段分辨率本已紧张。

## Consequences

- 副标题失去 CSS `text-overflow: ellipsis`，需改为按字数截断。
- 无障碍不受影响：可及名称由外层容器的 `role="timer"` 与 `aria-label` 提供，SVG 内容视为装饰。
- 空池态（尚未注墨）没有墨可挖，文字以阳文呈现——这与「未开始 / 进行中」的状态区分天然吻合，属额外收益。
