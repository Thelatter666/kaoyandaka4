# 深色主题不做阴文，计时文字恒为阳文

阴文（从墨中镂空、透出池底）依赖墨与池底之间的明度差。深色主题的池底本就是暗色，而墨是半透明荧光彩墨 —— 从半透暗墨里挖洞，露出的池底与周围墨几乎同亮度。原型实测该组合仅 **1.96:1**，低于大字号 3:1 的可读下限。

三条路线实测对比（像素级 WCAG 对比度，数字段 / 副标题段）：

| 路线 | 数字上 | 数字下 | 副标题 | 结论 |
|---|---|---|---|---|
| 墨不透明度提到 0.85，保阴文 | 6.31 | 4.85 | 4.86 | 达标，但下半盘变实心亮珊瑚，牺牲久盯静谧，副标题仅勉强过线 |
| 双主题都「浅池底 + 深墨」 | 7.68 | 7.41 | 7.13 | 达标，但深色主题里凭空出现一块浅色圆盘 |
| **深色恒阳文近白字 + 保半透荧光墨** | **15.53** | **8.21** | **8.21** | **采纳** |

决定：**浅色主题（用户日常主题）保留阴阳文切换；深色主题取消阴文，计时文字恒为近白实体字，墨保持半透荧光质感。** 这延续了既有的「双主题各自最优，不强行统一」原则，而非临时妥协。

实现上以纯 CSS 主题选择器覆盖 SVG 呈现属性（`clip-path: none` / `mask: none` / `fill`），不引入 JS 分支。

## Consequences

- ADR-0002 的阴文手法**仅适用于浅色主题**。
- 双主题的文字手法不一致是刻意的：**不要「统一」它**。把阴文强加回深色主题会把对比度打回 1.96:1，且不会有任何测试报错。
- 若日常主题改为深色，本决策应重新评估 —— 届时「双主题都浅池底 + 深墨」是更优选项（它保住阴文且对比度最高）。
